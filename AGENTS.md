# Coding conventions

Keep code simple, idiomatic, readable, and efficient. Follow DRY, KISS, and YAGNI.
Comment only non-obvious intent or necessary context; keep comments succinct.
Do not narrate rejected alternatives.

Commit each coherent unit of work. Use succinct Linux mailing list style commit
messages with an imperative subject and a body only when useful. Make the actual
change clear. End each commit message with this exact line:

signed-off by: <rafay11hadi@gmail.com>
